# ForelCards — единый файл сайта и админ-панели

Открой `index.html`. Админ-панель теперь встроена прямо в сайт: кнопка «Админ ↗» открывает её поверх каталога.

Пароль админа сохранён прежним: `ForeliAdmin2026!`

Карточки сохраняются в `localStorage` браузера, поэтому сайт и встроенная админка работают с одной и той же коллекцией.
